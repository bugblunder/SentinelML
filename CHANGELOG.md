# Changelog

## 2.0.0 — Portfolio research revision

- Consolidated detection into one reusable package with CLI and Streamlit entry points.
- Replaced upload-relative anomaly thresholds with independent temporal calibration.
- Added train-only rarity and identity baselines, 18 explicit features and causal ten-minute context.
- Added a lightweight PCA reconstruction baseline alongside Isolation Forest and five explicit rules.
- Rebuilt the dashboard for overview, investigation, evaluation and model transparency.
- Corrected whole-batch alert counts and preserved typed results.
- Added local SQLite feedback, safe byte-based exports and structured diagnostics.
- Added synthetic demo provenance, four-way ablation, three-seed results and documented failure cases.
- Added behavioral tests, lint/format checks and GitHub Actions CI configuration.
- Replaced unsupported chatbot/deep-learning claims with the actual v2 feature set.
- Excluded original private logs, environment files, model binaries and generated report clutter.
- Added architecture, data contract, project audit, research note and master's-application guidance.

## 2.0.1 — Publication cleanup

- Removed optional Docker packaging; the Python package, CLI and Streamlit workflow run directly without containers.
- Removed generated bytecode and local test-cache files from the source tree.
- Fixed CLI help formatting for the training split percentages.
- Clarified local-use and deployment security guidance in the README.
